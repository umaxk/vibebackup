Каталог {{range .SourceRoots}}{{end}}

Доступны только каталоги, смонтированные в контейнер (VBC_SOURCE_ROOTS).

Шаблоны проверяются по относительному пути и по имени файла на любом уровне вложенности.

База данных

Для PostgreSQL порт по умолчанию 5432, для MySQL/MariaDB — 3306. Если база в том же docker-compose, укажите имя сервиса (например, postgres). Если на хосте — host.docker.internal.

Формат cron: минута час день месяц день-недели. Пустое поле — только ручной запуск. 0 в «хранить» — использовать значение по умолчанию. Требуется включить хотя бы одну часть — каталог или базу.
